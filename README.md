# QuizFlix — Interactive Android TV Quiz Application

QuizFlix is an educational quiz application designed for television screens and remote-control navigation.

## Features
- Four quiz categories: General Knowledge, Computer Science, Artificial Intelligence, and Mixed Challenge
- Randomized multiple-choice questions
- 20-second countdown timer
- Correct and incorrect answer highlighting
- Score calculation and progress tracking
- Locally saved high scores
- Play Again and Back to Home navigation

## Tech Stack
- Java
- Android Studio
- Android SDK
- XML
- SharedPreferences

## How to Run
1. Clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle synchronization to complete.
4. Start a compatible Android TV emulator.
5. Run the application.
6. Navigate using the TV remote controls.

## Project Status
QuizFlix has been developed and tested using an Android TV emulator.
